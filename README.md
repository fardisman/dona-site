# DONA — donachoco.uz

Сайт шоколада DONA: главная, HIGH-END, LIGHT SIDE OF THE MOON, корзина.

- `media/` — рендеры и видео с 3D-моделей DONA
- `models/` — 3D-модели конфет в разрезе (glTF, gzip)
- `api/order.js` — отправка заказа в Telegram (переменные `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID` в Vercel)
